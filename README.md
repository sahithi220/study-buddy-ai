🌱 StudySprout – AI Study Assistant Web App

✨ Learn Better. Revise Faster. Grow Smarter.

StudySprout is a modern AI-powered study assistant web application designed to help students simplify learning, manage notes, and prepare effectively for exams — all in one place.

🎯 Project Overview

📚 StudySprout helps students:

understand concepts easily
revise quickly before exams
organize notes in a clean workspace

Instead of switching between multiple tools, StudySprout provides a single smart platform for learning.

💡 Problem It Solves

❌ Students struggle with:

long and unorganized notes
last-minute revision stress
difficulty understanding complex topics

✅ StudySprout solves this by:

converting notes into summaries
providing AI-style explanations
offering quick revision tools
🚀 Features

✨ Core Features:

📤 Upload Notes (file name support)
